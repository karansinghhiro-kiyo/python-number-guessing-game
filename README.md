# 🎯 Number Guessing Game 🐍

My first Python project.

A simple number guessing game made with Python.

## 🎮 How to Play

* Python randomly chooses a number between 1 and 100.
* Enter your guess.
* The game tells you if your guess is too high or too low.
* Keep guessing until you find the correct number.
* 🏆 Your total attempts are displayed when you win.

## 🛠️ Concepts Used

* Python basics
* `random` module
* `while` loop
* `if / elif / else`
* `break`
* User input
* Attempt counter

Built while learning Python basics. 🚀
